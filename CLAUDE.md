# Claude Code / CCR / Hermes / Harvey: RunYourAI Website Rules

**MANDATORY:** Read [AGENTS.md](AGENTS.md), [docs/WEBSITE-NORTH-STAR-QC.md](docs/WEBSITE-NORTH-STAR-QC.md), and [WEBSITE-QC-STANDARD.md](WEBSITE-QC-STANDARD.md) **before any website planning, implementation, redesign or QC**.

This covers **ALL** websites: customer deliveries, prospect demos, one-page mockups and prototypes. Mockups must meet the same premium visual/conversion standard as paid sites. Do not substitute a generic template. Never invent client facts or testimonials. Broken images, dead navigation, unusable forms, inconsistent styling and failed mobile layouts are stop-ship failures.

Before claiming completion, check business fit, conversion flow, technical function, premium visual polish and whole-site consistency. Report each as PASS, FAIL or NOT VERIFIED with evidence; say what was not tested. Commit/push/deploy success is not a QC pass.

When working in another repository, first ensure equivalent agent instructions and quality standards are actually available there; do not assume these instructions propagate automatically.
